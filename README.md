🔢 Números Pares e Ímpares até 100
---
Projeto desenvolvido em Portugol com o objetivo de praticar fundamentos de lógica de programação. O programa percorre os números de 0 a 100, identifica quais são pares e ímpares e organiza os resultados em listas separadas.

---

⚙️ Funcionalidades
Percorre automaticamente os números de 0 a 100;
Identifica números pares e ímpares através do operador %;
Conta a quantidade de números pares e ímpares;
Armazena os números encontrados em listas separadas;
Exibe os resultados de forma organizada no terminal.

---

🧠 Conceitos praticados:
Estrutura de repetição para;
Estruturas condicionais se e senao;
Operadores aritméticos e relacionais;
Variáveis inteiras e cadeias de caracteres;
Contadores;
Concatenação de strings;
Raciocínio lógico e organização de dados.

---

Tecnologia: Portugol
